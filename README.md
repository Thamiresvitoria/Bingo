# 🎱 Sistema de Bingo em JavaScript

## 📖 Sobre o projeto

Este projeto foi desenvolvido como atividade da UC2, com o objetivo de criar um Sistema de Bingo executado pelo terminal utilizando JavaScript. O sistema aplica conceitos fundamentais da linguagem, como variáveis, vetores, objetos, funções, estruturas de repetição, estruturas condicionais e manipulação de arrays.

## 🚀 Funcionalidades

* Sortear números aleatórios de 1 a 75;
* Impedir que um mesmo número seja sorteado mais de uma vez;
* Exibir os números sorteados em ordem crescente;
* Mostrar o histórico completo dos sorteios;
* Pesquisar se um número já foi sorteado;
* Reiniciar o bingo, limpando o histórico e restaurando todos os números disponíveis.

## 🛠️ Tecnologias utilizadas

* JavaScript (Node.js)
* readline-sync

## ▶️ Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone [URL_DO_REPOSITORIO](https://github.com/Thamiresvitoria/Bingo)
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Bingo
   ```

3. Instale a dependência:

   ```bash
   npm install readline-sync
   ```

4. Execute o projeto:

   ```bash
   node bingo.js
   ```

## 📋 Menu do sistema

```text
1 - Sortear número
2 - Mostrar números em ordem crescente
```
